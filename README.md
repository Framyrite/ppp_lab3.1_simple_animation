## Описание проекта

Программа представляет собой графическое приложение,
визуализирующее систему частиц с использованием Python.

Частицы создаются со случайными характеристиками,
двигаются по экрану и имеют ограниченное время жизни.

## Функциональные возможности

Планируется реализовать:

- Генерацию частиц со случайными параметрами.
- Отображение частиц в виде окружностей.
- Анимацию движения частиц.
- Ограниченное время жизни каждой частицы.
- Постепенное изменение прозрачности частиц.
- Создание новых систем частиц нажатием мыши.

## Используемые технологии

- Python 3.9+
- tkinter
- Pillow
- random
